# 惩罚与奖励  
**惩罚**  

- 第8至10次食用同一种食物时，饱食与饱和度恢复为原始值的50%。
- 第11至13次食用同一种食物时，在前一档基础上再减半，即恢复为原始值的25%。
- 第14次起，饱食与饱和度恢复为0，并施加饥饿效果，持续5秒，等级I。
- 第16次起，施加饥饿、反胃效果，持续10秒，等级II。
- 第18次起，施加饥饿、反胃、虚弱效果，持续20秒，等级III。
- 第23次起，施加挖掘疲劳、虚弱效果，持续60秒，等级V。
- 第33次起，施加反胃效果，持续60秒，等级V。

挑食：将会根据惩罚部分来进行对tooltip的修改  
“尝起来不错”：0-7次
“尝起来一般”：8-10次
“我不想吃这玩意儿了！”：11-13次
“令人作呕”：14次及以上
___
**奖励**    
每当食用3次不同种类的食物（记作A），将会奖励随机正面效果，5秒，等级I   
每当食用A+4次不同种类的食物（记作B），将会奖励随机正面效果，10秒，等级II   
每当食用B+5次不同种类的食物，将会奖励随机正面效果，20秒，等级III        
每当食用15次不同种类的食物，将会奖励随机正面效果，60秒，等级III

___
**特性**  重要提示：特性这部分内容暂时不需要去做！！
可能需要标签驱动   
“超重”：如果玩家吃了太多的主食（10个），玩家会变“超重”继续吃除了蔬菜水果外的任何东西都会被惩罚   
超重惩罚：增加超重效果，并让玩家活动速度降低。    
何以解？：吃10个蔬菜/水果（都用forge标签和继承diet的标签）  

**重置：**  
只记录150种已经食用的食物，然后重置。
